# Game Directory

This is the Godot project root. When development begins, `project.godot` is
created here via `/setup-engine`. The Godot editor's FileSystem dock will show
only this directory and its children — studio infrastructure at the repo root
(`design/`, `docs/`, `production/`, `.claude/`) is invisible to the engine.

## Structure

- `src/` — Game source code (GDScript, C#). See `src/CLAUDE.md` for coding
  standards, engine-specialist routing, and verification-driven development rules.
- `assets/` — Game art, audio, VFX, shaders, data assets.
- `tests/` — GUT unit tests and integration tests. Tests live here, NOT in `src/`.
- `prototypes/` — Throwaway wireframe scenes generated by `/preview-scene`.
  Gitignored. Safe to delete any time. Do NOT extend these scenes.

## Agent routing

When writing or editing files under `game/`, follow the engine-specialist routing
table in the root `CLAUDE.md` → Technical Preferences → Engine Specialists.

## Godot project setup

Run `/setup-engine` to initialise `project.godot` here when the team moves from
Design to Development stage. Do not create `project.godot` manually — the skill
sets up the correct Godot version, rendering backend, and project settings.
