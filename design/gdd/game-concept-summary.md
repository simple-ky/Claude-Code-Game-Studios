# Last Stand: Champions — Game Summary

## Overview
A top-down hero-defense roguelite. Pick a Champion with unique abilities, deploy AI survivor squads as placeable towers, and defend humanity's last outpost against endless zombie hordes. Every run tells a different story depending on your Champion.

- **Genre**: Top-down hero-defense roguelite (tower defense + hero-shooter hybrid)
- **Platform**: PC (Steam / itch.io)
- **Session Length**: 30–60 min per run, 10-wave structure
- **Monetization**: Premium one-time purchase
- **References**: Orcs Must Die! 3, Gunfire Reborn, Hades, Vampire Survivors, Risk of Rain 2

## Core Hook
Each Champion fundamentally reshapes how the game plays — not just which stats scale. Choosing the Sharpshooter feels like a tactical shooter. The Engineer feels like pure tower defense. The Berserker feels like Vampire Survivors. This is Hades' "weapon = game mode" principle applied to a top-down tower defense. A card-roll upgrade system layers on top of Champion identity each run, creating unique build combinations every session.

## Core Mechanics

1. **Champion-driven combat** — Each Champion has a signature weapon, unique active skill, and unique passive ability. 4 Champions at V1. Every Champion has a distinct movement speed, fire rate, and VFX style.
2. **Roguelite card-rolls** — Between each wave, pick 1 of 3 rolled cards (stat boosts, ability modifiers, new weapon variants, synergies). Cards interact specifically with Champion kits.
3. **Placeable AI squad towers** — Spend earned resources placing survivor units between waves: rifleman, engineer drone, trap, barricade. Units fire autonomously during waves. 3–6 placements per run.
4. **Wave-based horde escalation** — 10 waves per run, scripted zombie compositions attacking from 2–3 lanes. Difficulty scales through composition (lane pressure, special zombie types), never HP inflation.
5. **Meta-progression (variety only)** — Between runs, spend meta-currency to unlock new Champions, cards into the global pool, and maps. Never numerical power boosts.

## Core Loop

**Wave cycle**: 30–60s prep → 2–4 min wave → 30s card-roll and loot.

**Run structure** (10 waves):
- Waves 1–3: Establish build direction, place first towers, learn Champion cooldowns
- Waves 4–6: New zombie types introduced, first map hazard shift, mini-boss at Wave 5
- Waves 7–9: Apex pressure — screen-filling hordes, rare card drops, forced build decisions
- Wave 10: Boss fight. Survive = victory. Die = defeat. Both grant partial meta-currency.

**Moment-to-moment**: Shoot zombies → reposition → use active skill on cooldown → scan lanes for leaks → reinforce tower placements with available resources.

## Game Pillars

1. **Every Champion Plays a Different Game** — Champion choice changes run feel fundamentally, not just which numbers grow.
2. **Satisfying Kills, Always** — Every zombie death is visceral: gibs, hit-flash, screen shake, sound punch. Difficulty never trades kill-feel for challenge.
3. **Build Variety Beats Build Depth** — The fun is discovering new combinations each run, not optimizing one known build.
4. **Low Skill Floor, High Expression Ceiling** — Anyone who can aim and click should have fun on run 1. Mastery grows through build creativity and system knowledge, not reaction time.

## Visual Identity: Neon-Noir Pixel Apocalypse

**Rule**: "Muted world, neon threat."
- Environment: desaturated grays, browns, deep blues (~#2A2E33 base)
- Hot neon (pink/cyan/yellow) reserved exclusively for abilities, threats, and loot
- 2D pixel art with dynamic lighting from muzzle flashes and VFX
- Silhouette-first enemy design — zombies readable at any zoom by silhouette alone
- References: Hotline Miami (palette discipline), Hyper Light Drifter (neon restraint), Nuclear Throne (readable chaos)

## Champions (V1 — 4 total)

| Champion | Signature Style | Unique Mechanic |
|---|---|---|
| Sharpshooter | Precision, slow-time | Time-dilation active skill |
| Engineer | Pure tower defense | Converts zombie corpses into turrets |
| Medic | Sustain / support | Commands loyal survivor-dogs |
| Berserker | Aggressive brawler | Heals on kill, high risk/reward |

## Zombie Types (MVP — 5 types)
Basic (slow walker), Runner (fast, fragile), Tank (high HP, slow), Charger (straight-line rush), Swarmer (tiny, large groups that surround and flank)

## MVP Scope
- 2 Champions with dramatically distinct feel
- 20 cards
- 1 map with 2 lanes
- 5 zombie types
- 5-wave runs (~10–15 min for rapid iteration)
- Core juice pipeline: hit-stop, screen shake, particles, layered audio
- Functional card-roll between waves
- No meta-progression, no bosses, placeholder art acceptable
