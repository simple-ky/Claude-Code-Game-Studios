# Claude Code Game Studios — Obsidian Vault

A learning-friendly, navigable explanation of this repo. Open this folder as a vault in Obsidian and the graph view will light up.

> This vault explains the **studio template**, not the game built with it. It complements `docs/WORKFLOW-GUIDE.md` by being shorter, linked, and progressive.

---

## How to open in Obsidian

1. Install [Obsidian](https://obsidian.md/) (free).
2. Open Obsidian → **Open folder as vault** → select `docs/obsidian-vault/`.
3. (Optional) In **Settings → Appearance**, enable "Show inline title" so file headings match.
4. Press **Ctrl+G** (or **Cmd+G**) to open the graph view — you should see clusters by phase, agent tier, and document type.

### Recommended core plugins

Enable in **Settings → Core plugins**:

- **Graph view** — see the studio map visually
- **Backlinks** — see what links to the current note
- **Outline** — H2/H3 navigation per note
- **Tags** — filter by `#phase`, `#agent`, `#skill`, `#doc`

### Recommended community plugins (optional)

- **Mermaid** support is built-in — no plugin needed.
- **Excalidraw** — for hand-drawn studio diagrams.
- **Dataview** — query frontmatter (e.g. "all skills used in Phase 3").

## How notes link together

Every note links **up** (to its parent map), **across** (to siblings), and **down** (to specific instances). For example:

- A **phase** note links to its skills, agents, and documents.
- A **skill** note links to the phase it belongs to and the agent that runs it.
- An **agent** note links to its tier, the skills it appears in, and any document it owns.

The graph view shows these connections. Use **Ctrl+Click** to follow links; **Alt+←** to go back.
